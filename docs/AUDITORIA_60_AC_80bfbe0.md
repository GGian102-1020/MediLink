## Limitaciones: por que este informe no autoriza cerrar el MVP
- AC-48 tiene un fallo de CI; faltan el log de Playwright y la evidencia final de rol/Firefox, Edge y refresco. Los ocho PNG de Chromium prueban solo navegacion publica, no la sesion completa.
- Varios AC concurrentes estan validados a nivel de servicio con PostgreSQL, pero el protocolo normativo exige tambien comprobar el efecto HTTP concurrente; conservamos PARCIAL donde falto.
- Reglas temporales probadas solo con SuspensionPlanner sin persistir los intervalos historicos completos quedan PARCIAL.
- El hardware/carga/dataset del benchmark son reducidos; el p95 se registra como PASS de referencia, no como cierre de RNF-11 en el entorno final.
- La matriz normativa original NO se modifica ni se marca toda PASS. No se puede certificar un escenario ausente basandose en un workflow verde.
- `DIRECTo` es dictamen tecnico de esta revision, no certificacion contractual ni validacion humana. La aceptacion final requiere traza completa por AC, commit, entorno y operador.
