## Causa raíz del fallo visual

El runner declaró `const URL = 'https://localhost:8443'` y más adelante ejecutó `new URL(response.url())`. La variable `URL` local ocultaba al constructor global de JavaScript. El error ocurrió dentro del listener de respuestas de Playwright, antes de completar la prueba autenticada. **No hay evidencia de una falla real de sesión provocada por este mensaje de error.**

La corrección posterior (parche 13) renombra la constante a `BASE_URL`, separa el análisis de rutas en `ui_url.mjs` y agrega pruebas Node ejecutadas por GitHub Actions antes de lanzar los navegadores. **Estos cambios no están verificados por el commit `9c831b1`: necesitan un nuevo run del commit que los incorpore.**
